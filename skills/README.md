## Upload a skill

1. Download the `SKILL.md` file.
2. In Cowork, open **Customize**, filter by **Skills**, and select **Add > Upload**.
3. Start a new conversation, type `/` and select the skill to test it.
4. To share, open the skill and select **Share > Specific users in your organization**.

## Adapt a skill

Replace the Contoso formats, targets and rules with your own, and keep:

- a clear `description` that says **when** to use the skill,
- explicit steps, output format and rules,
- the version number in the description.
