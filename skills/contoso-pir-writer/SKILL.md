# Contoso post-incident review

## Steps
1. Build a timeline from all sources (time, event, source, role). Flag conflicts between sources.
2. Calculate time to detect, time to declare, time to restore and total duration. Compare with the SLA for the priority (P1 restore 4 hours, P2 8 hours).
3. Analyse the root cause with 5 Whys. Separate root cause from contributing factors.
4. Write the PIR in Word using the structure below.
5. Create an action register in Excel.

## Structure
Summary; Impact; Timeline; Detection; Response; Root cause (5 Whys); Contributing factors; What went well; What did not go well; Actions; Sources.

## Rules
- Blameless: describe roles, processes and systems, never individuals.
- Mark inferred statements with [Inferred].
- Every action has an owner role, a due date and a priority.
- Reference the contract clause when a vendor obligation applies.
