# Cowork apps for IT

[Home](../README.md) | [Module 4: Cowork apps](../modules/04-cowork-apps.md)

Five working IT apps you can build with Cowork from a plain-language description, using the practice workbook as seed data.

| ID | App | Users | Replaces | Seed data |
|----|-----|-------|----------|-----------|
| [APP-01](APP-01-major-incident-command-board.md) | Major Incident Command Board | Major Incident Manager (edit) and others | A shared spreadsheet, a whiteboard photo and several chat threads during every P1 | Incidents, Major_Incident_Log |
| [APP-02](APP-02-change-calendar-cab-tracker.md) | Change Calendar and CAB Tracker | Change Manager (edit) and others | Emailed change lists, manual conflict checks and CAB decisions recorded in minutes | Changes |
| [APP-03](APP-03-licence-and-asset-tracker.md) | Software Licence and Asset Tracker | Software Asset Manager (edit) and others | Separate licence, renewal and device spreadsheets that are never in sync | Licences, Licence_Usage, Devices |
| [APP-04](APP-04-access-review-tracker.md) | Access Review Campaign Tracker | Identity team (edit) and others | Quarterly access reviews run by email and spreadsheet attachments | Access_Review |
| [APP-05](APP-05-it-demand-intake.md) | IT Demand Intake and Prioritisation | Business requesters (submit) and others | Project and enhancement requests sent by email and discussed without a common scoring method | Demand_Intake |

## How to run every app lab

1. Download the [practice workbook](../reference-files/Contoso-IT-Practice-Data-Workbook.xlsx).
2. Open Cowork, start a new conversation and attach the workbook.
3. Paste the `/app` prompt from the app page.
4. Answer Cowork's clarifying questions and review the data design it proposes.
5. Review the preview, iterate, then publish and share with a test group.

> The App skill may be a Frontier capability in your tenant. If `/app` is not available, ask your admin.
