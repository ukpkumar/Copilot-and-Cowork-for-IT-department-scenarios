## How every lab works

1. Start a **new** Cowork conversation for each lab.
2. Attach the reference files with **+ > Upload** (or reference them from OneDrive).
3. Copy the prompt from the lab, paste it, and **read the plan** Cowork proposes before it starts.
4. Compare the result with the **What good looks like** checklist.
5. Tidy up at the end: pause scheduled tasks and delete practice drafts you do not need.
