# Glossary

[Home](../README.md)

| Term | Meaning |
|------|---------|
| Agent flow | A deterministic automation in Copilot Studio that can include AI steps and human approvals; can be used as a tool by an agent |
| App skill | The Cowork skill (`/app`) that builds working business apps from a description |
| Autonomous agent | A Copilot Studio agent started by a trigger (event or schedule) without a user |
| CAB | Change Advisory Board |
| Connector | A link to a data source or service, used by plugins and Copilot Studio agents |
| Copilot Credits | The usage-based billing unit for Cowork and agents |
| Copilot Studio | Low-code studio for building and governing agents and workflows |
| Cowork | The Microsoft 365 Copilot experience that plans and completes multi-step work |
| DLP | Data loss prevention; in Power Platform, policies that control which connectors can be used together |
| Event-driven task | A Cowork task that runs when a matching email or Teams message arrives |
| JML | Joiner, mover, leaver |
| MCP | Model Context Protocol, an open standard for connecting AI to tools and data |
| PIR | Post-incident review |
| Plugin | A package of skills and connectors deployed to users by admins |
| Scheduled task | A Cowork prompt that runs on a recurring schedule |
| Skill | A reusable instruction file (`SKILL.md`) that teaches Cowork a specific task |
| Spending policy | The Microsoft 365 admin center setting that grants access to Cowork and sets usage limits |
